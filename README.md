# SKMHussain — Professional Portfolio

Responsive portfolio for Khaja Moinuddin Hussain Syed, focused on Microsoft Dynamics 365 CE, Power Platform, and Azure.

## Features
- Responsive portfolio with profile, expertise, selected projects, and career history
- Print-ready résumé page: open `resume.html`, then choose **Print / Save as PDF**
- Semantic HTML, Open Graph metadata, mobile navigation, and reduced-motion support
- Plain HTML, CSS, and JavaScript; no build step required

## Run locally
Serve this directory with any static HTTP server, e.g. `python -m http.server 8000`, then visit `http://localhost:8000`.

## GitHub Pages
Enable Pages in repository Settings → Pages and select the `main` branch / root folder.
